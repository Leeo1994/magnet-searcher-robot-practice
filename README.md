# robot navigation assessment

University of Bristol Robotic Systems coursework (Arduino IDE).

## Features
- Homogeneous and inhomogeneous (refractory period) Poisson spike generators
- Fano factor and CV calculation to measure spiking variability
- LIF neuron model with constant, Poisson, and stimulus-driven input
- Spike-triggered average (STA) of recorded motion stimulus data, including adjacent vs. non-adjacent spike pairs
